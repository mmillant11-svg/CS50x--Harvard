# CS50x Harvard - Introduction to Computer Science

Portafolio de proyectos en C para la Beca Tech Vélez Reyes - Universidad del Norte.

Soy estudiante de CS50x (Harvard) y este repositorio documenta mi aprendizaje en fundamentos de Ciencias de la Computación.

### Proyectos incluidos:

1. Credit - Validador de tarjetas de crédito
Implementa el Algoritmo de Luhn para validar y identificar si una tarjeta es VISA, MASTERCARD o AMEX.
- Reto: Manejo de números largos y validación de checksum.
- Lenguaje: C

2. Readability - Analizador de legibilidad
Calcula el nivel escolar necesario para entender un texto usando la fórmula de Coleman-Liau. Cuenta letras, palabras y oraciones automáticamente.
- Reto: Manipulación de strings y fórmulas matemáticas.
- Lenguaje: C

3. Scrabble - Juego de puntuación
Programa que determina el ganador de una partida de Scrabble calculando el valor de cada palabra.
- Reto: Uso de arrays y funciones.
- Lenguaje: C
